## What I maintain

- **[TestivAI](https://github.com/testivai/testivai-oss)** — MIT-licensed, local-first visual regression testing. Pixel diff plus DOM and computed-style comparison, so a failing snapshot says *which element* changed and whether the pixels are likely render noise. Adapters for Playwright, WebdriverIO and Selenium (npm), Python (PyPI) and Ruby (RubyGems); a GitHub Action with `/testivai approve` on the PR; an MCP server so coding agents can read the results and see the diffs. No account, no API key, no server.
- **[lighthouse-ruby](https://github.com/mcbuddy/lighthouse-ruby)** — Ruby wrapper for `lighthouse-cli`. Forked from the original after it was archived; I publish and maintain the [gem on RubyGems](https://rubygems.org/gems/lighthouse-ruby).
